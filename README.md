# CSS Structure
- Bootstrap
    Only used for grid system and utility classes.

[//]: # (- https://getbootstrap.com/docs/5.3/getting-started/contents/#css-files)
- Custom CSS
    - Variables
        Define colors, fonts, and spacing variables for consistency.
    - Base Styles
        Set global styles for body, headings, paragraphs, and links.
    - Layout
        Styles for header, footer, and main content area.
    - Components
        Styles for buttons, forms, cards, and other reusable components.
    - Utilities
        Custom utility classes for margin, padding, text alignment, etc.
